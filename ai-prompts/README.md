# 📚 Índice de Prompts Mestres - Antigravity\n\n> Guia completo de todos os prompts otimizados para usar com Claude.\n\n## 🎯 Estrutura de Prompts\n\nCada prompt mestre é um template reutilizável que você preencherá com seus dados específicos e enviará ao Claude para obter respostas estruturadas e consistentes.\n\n## 📖 Prompts Disponíveis\n\n### 1. **Story Generation** (Geração de Roteiros)\n📄 Arquivo: `ai-prompts/story-generation.md`\n\n**Quando usar:**\n- Criar novo roteiro do zero\n- Desenvolver narrativa completa\n- Definir 3 atos, personagens, cenas\n\n**Entradas:**\n- Briefing com duração, formato, objetivo\n- Tom desejado\n- Referências visuais\n\n**Saídas:**\n- Sinopse (2-3 linhas)\n- Personagens detalhados\n- Breakdown de cenas com timing\n- Diálogos/narrações completos\n- Notas técnicas\n- Triggers emocionais mapeados\n- Gaps identificados\n\n**Tempo estimado:** 20-40 minutos\n\n**Exemplo de fluxo:**\n```\nVocê → Preenche briefing\n  ↓\nVocê → Envia para Claude com o prompt\n  ↓\nClaude → Gera roteiro completo\n  ↓\nVocê → Salva em `scripts/stories/projeto-XX-roteiro.md`\n  ↓\nVocê → Próximo prompt para breakdown\n```\n\n---\n\n### 2. **Scene Breakdown** (Decomposição de Cenas)\n📄 Arquivo: `ai-prompts/scene-breakdown.md`\n\n**Quando usar:**\n- Após ter roteiro, precisa detalhes técnicos\n- Preparar cena para render/produção\n- Gerar comandos FFmpeg/Blender\n\n**Entradas:**\n- Cena do roteiro (narrativamente)\n- Especificações técnicas (resolução, fps)\n- Restrições (software, tempo)\n\n**Saídas:**\n- Descrição visual frame-by-frame\n- Timeline detalhada com timing\n- Animações específicas\n- Cores em hex codes\n- Comandos FFmpeg/Blender sugeridos\n- Efeitos com parâmetros exatos\n- Checklist técnico\n\n**Tempo estimado:** 15-30 minutos por cena\n\n**Exemplo:**\n```\nRoteiro: \"Câmera zoom-in em personagem, cores mudam de azul para vermelho\"\n  ↓\nBreakdown: Zoom (1.0 → 1.5) em 2000ms, easing cubic-out\n           Color transition #45B7D1 → #FF6B6B em 1500ms\n           FFmpeg command com valores exatos\n```\n\n---\n\n### 3. **Character Creation** (Criação de Personagens)\n📄 Arquivo: `ai-prompts/character-creation.md`\n\n**Quando usar:**\n- Desenvolver novo personagem\n- Manter consistência se reutilizar em vários vídeos\n- Criar \"character bible\" para referência\n\n**Entradas:**\n- Nome, função, contexto\n- Inspiração visual\n- Personalidade, motivações\n- Voz (se narrador)\n\n**Saídas:**\n- Descrição física completa\n- Paleta de cores pessoal\n- Arco narrativo\n- Voz/maneirismos\n- Linguagem corporal\n- Relacionamentos com outros personagens\n- Referências visuais\n\n**Tempo estimado:** 20-30 minutos por personagem\n\n**Uso prático:**\n```\nCharacter Bible → Salvo como JSON\n  ↓\nReferência em todos os vídeos com personagem\n  ↓\nConsistência visual/vocal garantida\n```\n\n---\n\n### 4. **Trigger Mapping** (Mapeamento de Gatilhos Emocionais)\n📄 Arquivo: `ai-prompts/trigger-mapping.md`\n\n**Quando usar:**\n- Analisar roteiro completo\n- Otimizar pacing e emoção\n- Identificar gaps narrativos\n- Intensificar impacto emocional\n\n**Entradas:**\n- Roteiro completo\n- Duração total\n- Emoções desejadas\n- Público-alvo\n\n**Saídas:**\n- Triggers visuais, sonoros, narrativos\n- Curva emocional visual\n- Gaps narrativos com soluções\n- Análise de pacing\n- Pontos críticos (hook, clímax, resolução)\n- Sugestões de otimização\n- Timeline detalhada com emoções\n\n**Tempo estimado:** 20-40 minutos\n\n**Resultado:**\n```\nCurva de Emoção:\n100% │                    ╱╲\n     │                   ╱  ╲\n 50% │  ╱╲            ╱      ╰─\n     │ ╱  ╰────────╱\n  0% │╱_____________________\n     └─────────────────────\n     0s  Hook | 10s Dev | 25s Climax | 30s Fim\n```\n\n---\n\n## 🔄 Fluxo Completo de Uso\n\n```\n┌─────────────────────────────────────────────────────────────┐\n│ anteriores\n- Construa library de prompts personalizados\n\n### 2. **Iteração é Chave**\n- Primeira geração: nunca é perfeita\n- Revise com Claude: \"Pode intensificar o clímax em 20%?\"\n- Múltiplas versões até ficar satisfeito\n\n### 3. **Contexto é Tudo**\n- Quanto mais detalhes no briefing, melhor a resposta\n- Forneça referências visuais/sonoras\n- Explique restrições técnicas\n\n### 4. **Use em Sequência**\n- Não comece pelo Scene Breakdown\n- Sempre: Story → Triggers → Breakdown\n- Ordem importa para consistência\n\n### 5. **Documente Decisões**\n- Salve cada versão do prompt\n- Anote por que fez mudanças\n- Crie histórico do projeto\n\n## 🔗 Relacionamento Entre Prompts\n\n```\nStory Generation\n    ↓\n    ├→ Character Creation (para cada personagem)\n    │\n    └→ Trigger
