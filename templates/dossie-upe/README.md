# Modelo de dossiê Upe

`Modelo_Dossie_Upe.html` é um arquivo único e limpo (sem dados de nenhuma marca) para gerar o dossiê de uma nova marca com as mesmas 5 abas: Diagnóstico, Pesquisa e estratégia, Redesign, Entregáveis e Apresentação (player com tela cheia, motions com som, Instagram com zoom e versão PDF).

Todo o conteúdo fica no objeto `DADOS`, no topo do arquivo. Campos entre `[colchetes]` aparecem destacados até serem preenchidos; listas vazias escondem o bloco. As instruções completas (pastas esperadas e como pedir ao Claude) estão no comentário do topo do HTML.
